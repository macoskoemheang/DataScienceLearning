### Examples

```bash

```

**Jupyter Notebook** — launch the notebook server and create a new `.ipynb`:
```bash
jupyter notebook
```

**Visual Studio Code** — open this folder in VS Code:
```bash
code .
```

**GitHub** — clone a repo and push your changes:
```bash
git clone https://github.com/username/repo.git
git add .
git commit -m "Add Python basics examples"
git push
```

**Anaconda** — create and activate an isolated environment:
```bash
conda create -n ds-learning python=3.11
conda activate ds-learning
```
